# 德鲁伊野兽形态独立页：设计与执行方案

日期：2026-09-20。状态：设计已确认，正式接入及 Chromium 验证已完成。

交互 Demo 已完成评审；正式页面接入后，按用户要求清理了 Demo 与浏览器验证产物。以下保留设计及验证记录。

## 1. 目标与本次交付

将野兽形态做成与游侠伙伴、Iknis 主板扩展同级的可选角色表页面。阅读时只占一个 A4 区域，通过内部翻页查看内容；打印预览和打印时展开全部物理页，排列在主板扩展之后、冒险笔记之前。

本次交付完整执行方案、独立交互 Demo 与正式页面实现。Demo 使用仓库内置的全部 24 个形态，展示位阶跳转、前后翻页、显示开关、打印预览和 PDF 输出；顶部其他角色表标签是位置示意。Demo 的数据是用于评审的快照，不作为正式内容来源。

## 3. 产品范围与默认决策

1. 「野兽形态」是一个可选标签，通过现有「+ 页面管理」开启。新旧角色默认关闭，用户打开后跟随当前角色保存；职业变更不强制开关。
2. 第一版提供现有内置 24 个形态的完整参考表。所有位阶均可阅读，不按角色等级隐藏高位阶内容，也不自动进行变形或修改角色数值。
3. 正式内容从现有卡牌运行时读取，限定内置野兽形态来源，尊重内置包禁用状态。用户自定义形态的混排、筛选和任意长度自动分页另立需求，不隐式加入第一版。
4. 翻页位置属于视图状态，不写入角色数据。父层按「当前角色 + 页面槽位」保存会话内页码，切换标签或返回打印预览后保留；切换角色回到第一页，刷新重置。
5. 无内容时保留可见的说明页及页面管理入口，打印时跳过空内容组。加载状态与空内容必须区分，读取失败展示明确错误，不能用另一套硬编码正文兜底。
6. Demo 的手机阅读沿用当前项目的 A4 原尺寸方案，局部横向滚动；正式接入使用既有页面容器。整站移动端重排不在此任务内。

以上是用于执行的默认范围，评审时可调整；无需先决定额外的收藏、形态选择或自动化行为。

## 4. 排版规范

### 页面骨架

- 屏幕：宽 210mm、高 297mm，固定高度；外观沿用现有 `.a4-page` 的白底、小圆角和阴影。
- 顶部复用 `PageHeader` 的深灰页眉，表头、边框和辅助文字使用项目已有的 Tailwind 灰阶配置。正文使用现有 Arial / Helvetica / 系统中文字体，不引入新字体或装饰插画。
- 标题「野兽形态」24px 加粗，右侧显示「位阶 N」及适用角色等级；辅助文字 12px。
- 内部导航放在标题下：左侧位阶跳转，右侧「上一页 / 页码 / 下一页」。导航位于纸张范围内，外部标签始终只有一个「野兽形态」。
- 规则提示只给出变形消耗与位阶限制，明确完整变形规则见职业卡，避免误当完整职业规则。
- 正文采用左右 30% / 70% 的参考表：左侧名称、动物示例、属性、攻击和优势；右侧完整形态特性。深灰表头、灰底左栏、细分隔线与现有表单风格一致。
- 形态名称 16px，特性正文 13px、行高 1.6；元信息 11–12px。正文复用 `components/ui/card-markdown.tsx` 的强调规则：`**文本**` 为深灰加粗，`***特性名***` 为琥珀色加粗（`#92400e`），`*状态词*` 为琥珀色直角引号（`#78350f`），例如「隐藏」「脆弱」「中毒」「束缚」。不改成下划线或普通斜体，阅读和打印保持一致，黑白打印仍能凭直角引号辨认。
- 状态样式由原文 Markdown 标记决定，不按关键词批量替换；页面开关文案中的“隐藏”属于普通界面文字。当前 24 个形态没有「隐藏」状态的实际条目，不为示例擅自修改规则正文。
- 页脚显示位阶和「野兽形态 n / N」；所有页页脚位置一致。
- 常规形态与传奇／神话升级、混种形态都保留全部正文；没有独立属性栏的数据不凭空补数值。原文空优势字段显示「—」。

### 分页规则

初版目标：位阶 1、2、3、4 各一张 A4，共 4 页，每页 6 个形态。位阶分别对应角色等级 1、2–4、5–7、8–10。

正式内容与分页清单分离：分页清单记录稳定形态 ID，不记录正文副本。阅读及打印使用同一清单，因此某形态在阅读第 n 页就会在打印第 n 张。

条目不得跨页，正文不得截断、折叠后漏印或依靠缩小字体硬塞。若某个位阶因实际字体或将来内容变长而溢出，应调整显式分页清单，新增「位阶 2 · 续」等页；位阶按钮跳到该位阶首张，前后按钮遍历所有物理页，页码来自清单长度。不能假定长期恒为 4 页。

分页是展示层职责。禁止将 DOM 测量结果作为业务数据或写进角色保存；第一版用明确分页清单与浏览器尺寸验证保证排版。

## 5. 交互约定

| 操作或状态 | 预期结果 |
| --- | --- |
| 打开野兽形态标签 | 显示该槽位的上次阅读页；首次显示位阶 1 |
| 点击位阶 | 跳到该位阶首张；当前位阶具有文字与视觉选中态 |
| 上一页 / 下一页 | 一次切换一张，不循环；首尾对应按钮禁用 |
| 翻页 | 页面外框、页眉和页脚不跳动；无内部正文滚动条 |
| 键盘操作 | 所有按钮可 Tab 聚焦、Enter/Space 操作；更新时保留合理焦点并播报页码 |
| 进入打印预览 | 展开所有野兽形态物理页，隐藏翻页控件 |
| 退出预览 | 回到原先阅读页；沿用现有 Esc 退出行为 |
| 关闭显示开关 | 从标签和打印中移除整组，不影响其他可选页 |
| 双页模式 | 左右槽位独立翻页；不会同时驱动另一侧的野兽形态页 |

不增加全局左右键监听，避免与角色表切页冲突。点击区域保持至少 44px；禁用按钮使用原生 `disabled`，当前页使用 `aria-current`，焦点轮廓清晰可见。

## 6. 打印设计

完整顺序：

`第一页 → 第二页 → 游侠伙伴（开启时） → 主板扩展（开启时） → 野兽形态 1…N（开启且有内容时） → 冒险笔记（开启时） → 聚焦卡组（有内容时） → 库存卡组（有内容时）`

- `PageDefinition` 增加可选专属 `printComponent`。打印渲染器显式选择专属组件；其他现有页面维持当前组件，这是多页呈现契约，不是数据失败兜底。
- `BeastFormsPrintPages` 用与阅读相同的 `BeastFormSheet` 渲染全部分页，不能只打印当前 React 页码。
- 打印组容器采用块布局，不能让现有外层 `flex` 将多张纸横向排布。
- 每个物理页主动分页；组后有卡牌时正常分页，组是最后内容时取消最后一张纸的尾随强制分页，避免空白尾页。
- 浏览器 A4 纸宽 210mm；现有 `@page` 左右各 5mm，所以本页打印内容宽度必须设为 200mm。不能同时使用 210mm 内容宽度加左右边距。
- 本页打印高度控制在 286mm 内，兼容现有 5mm 顶边距并留出舍入余量。只调整新页局部尺寸，不顺带改变其他角色表的打印缩放。
- 页眉、内容和页脚可以因打印可用宽度稍微重排，但形态所属分页不变；不以纯屏幕布局检查替代 PDF 验证。
- Demo 支持直接浏览器打印全部 4 页。正式版本同时检查应用「打印全部」以及直接 Ctrl/Cmd+P 的既有路径：可见野兽页必须展开所有内页，不可截到当前页；不得导致隐藏页面混入打印。

## 10. 风险与处理

1. **中文字体差异**：同一 13px 字号的换行和高度可能不同。以浏览器实测和 PDF 为准，保留余量；超过预算增加页数。
2. **原始文本质量**：已有文本中存在待校对表达，如「从位阶13中」。Demo 原样保留；内容修订需单独确认，不能借布局任务自行解释规则。
3. **正文结构变化**：投影必须通过完整性测试，禁止用脆弱正则静默吞掉新增段落。
4. **存储兼容**：新增开关键必须走完整 schema 变更链，不把缺字段修复塞进 React 组件或底层存储替换方法。
5. **全局打印 CSS**：旧页面默认 210mm 与页边距有现存张力，局部修复新页并回归邻接卡牌页，避免扩大改动范围。
