# Internationalization Context

This context defines the domain language for separating application interface translation from DaggerHeart rules-content localization.

## Language

**Application UI Copy**:
Text whose purpose is to operate the application interface rather than express DaggerHeart rules content.
_Avoid_: chrome, basic UI text, interface strings

**Sheet Field Label**:
A fixed label, section title, table header, or short placeholder on the character sheet layout that identifies a character-sheet field.
_Avoid_: rules content, generated label, card text

**Rules Content**:
DaggerHeart rules, character options, and built-in data content shown by the application.
_Avoid_: business data, card text, game text

**System-Generated Rules Label**:
A display label generated by the application from rules or automation state rather than directly authored by a user.
_Avoid_: automation text, generated copy, modifier label

**Locale Preference**:
The user's saved application-language choice.
_Avoid_: character language, sheet locale, save language

## Relationships

- **Application UI Copy** can be translated without changing character data.
- **Sheet Field Label** can be translated with **Application UI Copy** when it is fixed by the sheet layout.
- **Rules Content** belongs to DaggerHeart content localization and is separate from the first-stage UI translation scope.
- Built-in card names, equipment names, and rules option values are **Rules Content**, not **Sheet Field Label**.
- A **System-Generated Rules Label** sits between **Application UI Copy** and **Rules Content**; it must be translated only after its generated and user-authored parts are separated.
- A **Locale Preference** belongs to the application, not to a character sheet save.

## Example Dialogue

> **Dev:** "Should the card selection button and the card name both move into the first i18n pass?"
> **Domain expert:** "No. The button is **Application UI Copy**. The card name is **Rules Content** and needs the later content-localization design."

> **Dev:** "Can we translate the sheet labels `职业`, `名称`, and `闪避` in the first pass?"
> **Domain expert:** "Yes. Those are **Sheet Field Labels** because the sheet layout owns them."

> **Dev:** "Can we translate `升级：闪避 +1` as normal UI copy?"
> **Domain expert:** "Not yet. It is a **System-Generated Rules Label** because part of it is generated from automation state and part of it refers to rules terms."

## Flagged Ambiguities

- "界面 chrome" was used to mean first-stage translatable UI text; resolved: use **Application UI Copy**.
- "业务数据本地化" was used for DaggerHeart content; resolved: use **Rules Content**.
- "角色卡固定标签" was used informally for layout-owned field names; resolved: use **Sheet Field Label**.
